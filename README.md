# AyudaVital · Veröffentlichungskalender

Statische Seite (GitHub Pages) unter kalender.ayudavital.de. Team-Sicht und Sicht für HSE (`#hse`).

- `data.json` – alle Termine. Geplante Termine schreibt die monatliche Planungssitzung; den Stand (geplant / eingeplant / veröffentlicht) gleicht eine tägliche Aufgabe mit Metricool ab.
- `template.html` – Darstellung. `build.py` erzeugt daraus `index.html`.
